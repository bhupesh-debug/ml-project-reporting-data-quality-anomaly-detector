Q-P4-001 Which detector performs best overall?
▾
Direct Answer: The **Enhanced Multi-Tier Hybrid (Enhanced Rules + Contra Logic + Isolation Forest)** performs best, capturing **93.7% of all corrupted rows** (1,184 / 1,264), outperforming original rules (54.6%) and Isolation Forest alone (27.2%).
Evidence: 40% held-out test split evaluation across 9,600 transactions.
Q-P4-002 Why are sign flips difficult to identify using magnitude alone?
▾
Direct Answer: A sign flip produces a standard monetary amount; without account debit/credit context, amount-only algorithms see an ordinary transaction (0% recall). Adding an account-level direction check (`sign_vs_acct`, Odds Ratio 4.44x, $p < 0.0001$) elevated sign-flip recall to **80.9%**.
Evidence: Econometric Logit regression ($z=6.73, p < 0.0001$).
Q-P4-003 Which controls should be implemented upstream?
▾
Direct Answer: Upstream primary-key deduplication and NOT NULL constraints on mandatory entity keys eliminate 100% of duplicates (720 rows) and 100% of missing keys (240 rows) at zero analyst triage cost, saving $33,600/month in review labor.
Evidence: Root-cause taxonomy analysis and audit queue capacity simulation.
Q-P4-004 What audit trail and escalation controls should be implemented?
▾
Direct Answer: Implement SOX 404 audit logging capturing transaction ID, timestamp, model break probability score, triggered rule names, reviewing analyst signature, and remediation reason code.
